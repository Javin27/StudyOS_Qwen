- Takes 2 minutes

1. Push code to GitHub
2. GitHub Actions automatically builds APK
3. Download from Releases section
4. Install APK on Android

**See ANDROID_INSTALL_GUIDE.md for detailed steps**

## 📲 How to Install on Android

### After deploying (Options 1 or 2):

1. **Open the URL on your Android phone** (use Chrome browser)

2. **Wait for install banner** (appears automatically after 3 seconds)
   - OR tap the ⋮ menu (top right)
   - Tap "Install app" or "Add to Home screen"

3. **Confirm installation**

4. **Done!** StudyOS icon appears on your home screen!

### For APK (Option 3):

1. Download APK from GitHub Releases
2. Transfer to phone
3. Enable "Unknown sources" in Settings
4. Tap APK to install

## 🆘 Troubleshooting

**"Install button doesn't appear"**
- Make sure you're using Chrome on Android
- Try clearing browser cache
- Ensure you're on the deployed URL (not localhost)

**"App shows browser bar"**
- You didn't install it properly
- Uninstall and reinstall using the install prompt
- Make sure you tapped "Install" not just bookmarked

**"Netlify deploy failed"**
- Run `netlify login` first
- Check your internet connection
- Try again
